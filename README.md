## 🚀 开源项目

### Rshell - 跨平台多协议 C2 框架

Golang 编写、MIT 协议开源的 C2 框架，面向安服人员渗透测试与红蓝对抗场景：

- 🌐 **多协议上线**：WebSocket / TCP / KCP / HTTP / OSS，另含 SOCKS5 代理转发通道
- 🦀 **双语言客户端**：Golang 全平台覆盖（含 loong64 / mips 等国产化架构）+ Rust 重写版（更小体积、amice LLVM 编译期混淆）
- 📦 **单文件部署**：前端内嵌、无 CGO、免依赖，拷走即用
- 🖥️ **Web 可视化**：交互式终端、文件管理、插件系统、敏感信息搜索
- 🔒 **通信加密**：每客户端独立密钥，X25519 + AES-CFB
